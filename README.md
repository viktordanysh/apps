# AER & YouCan

Two browser apps by Viktor Danyshchuk (London), also published on the App Store.
Live: https://viktordanysh.github.io/apps/

| App | What it does | Links |
|---|---|---|
| **AER: Guided Breathing** | Guided breathing sessions with calming visuals, 432 Hz sound and several languages | [Web app](https://viktordanysh.github.io/apps/aer/) · [App Store](https://apps.apple.com/ca/app/aer-breath/id6761077610) |
| **Habit Tracker: You Can** | Track habits, routines, challenges and smoke-free days, one small step at a time | [Web app](https://viktordanysh.github.io/apps/youcan/) · [App Store](https://apps.apple.com/ca/app/habit-tracker-you-can/id6768371723) |

## About this repository

This repository holds the built, deployable web assets only (served with GitHub Pages).
Source code, native projects, API credentials and user data are not included.
Progress in the apps is stored locally in the user's own browser.
